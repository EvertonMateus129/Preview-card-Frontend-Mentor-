## My process

While working on this challenge, I started thinking more about how to place elements inside a box without losing the card layout, and how to keep the format consistent. To achieve this, I explored different sizing methods and started using rem units to make sizing easier.

Figma was essential during the build process. It helped me understand the challenge more clearly by showing me the colors, font sizes, and font weights. This made a big difference in my work.

The most challenging part for me was making the component responsive. I found it difficult to adapt the layout to different screen sizes, so I used Cursor for guidance. It also helped me understand the logic behind responsive design.
